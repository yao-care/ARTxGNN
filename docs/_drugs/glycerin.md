Actualmente no se dispone de datos detallados sobre el mecanismo de acción registrado para este informe. Se sabe que la glicerina actúa como agente osmótico e hiperosmótico, y que se usa como humectante y componente de vehículos en preparaciones.

Por lo tanto, el puntaje elevado debe interpretarse únicamente como una señal computacional que requiere validación independiente. No se debe considerar evidencia de eficacia.
